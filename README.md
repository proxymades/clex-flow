<h1 align="center">CLEX Flow</h1>
<p align="center">Визуальная среда разработки для микроконтроллеров</p>
<p align="center"><strong>0.1.14 · Предварительная версия · macOS / Windows · MIT</strong></p>

CLEX Flow – приложение для визуальной разработки прошивок микроконтроллеров. Выберите плату, нарисуйте подключения и соберите поведение устройства из блоков. Монтаж, логика и интерфейс дисплея сохраняются в одном проекте на вашем компьютере.

Сейчас поддерживаются ESP32, ESP32-S3, ESP32-P4 и Arduino Nano. Собирать и записывать прошивку можно из приложения.

Приложение находится в активной разработке. Стабильного релиза пока нет.

![Главный экран CLEX Flow](docs/images/home.png)

## Возможности

- **Проекты:** локальное хранение, поиск, импорт и экспорт JSON-файлов. Папку проектов можно выбрать на другом диске. Доступны ручное сохранение и автосохранение через 10 секунд без изменений.
- **Платы и компоненты:** поиск по модели и микроконтроллеру, фильтры по семейству и производителю. В «Монтаже» показаны физические подключения, а в «Логике» – события и действия добавленных устройств.
- **Монтаж:** изображения плат, контакты компонентов, проверка GPIO, питания и конфликтов ресурсов. Провода строятся с прямыми углами; их маршрут и сторону подключения можно менять вручную. Перемещение устройств, соединения и маршруты поддерживают отмену и повтор действий.
- **Логика:** события запускают действия, а связи данных передают числа, текст и значения Да/Нет. Доступны таймер, счётчик, секундомер, управление GPIO и сообщения в Serial. Подсказки объясняют назначение контактов; редактор подсвечивает совместимые соединения и проверяет порядок выполнения. [Работа с редактором](docs/logic.md).
- **Условия:** преобразование текста в число, сравнение чисел и диапазонов, проверки текста и значений Да/Нет. Условия можно объединять с помощью И, ИЛИ и НЕ. [Настройка и пример MQTT](docs/numeric-logic.md).
- **Выбор по значению:** запуск одной ветви по числу, тексту или значению Да/Нет. Для чисел и текста можно задать до 16 вариантов. Выбор выполняется по событию и использует последнее значение источника. Поддерживаются ESP32, ESP32-S3, ESP32-P4 и Nano. [Настройка и переключение ESP-NOW](docs/logic-selection.md).
- **MOSFET-ключи и реле:** управление 1-16 каналами, выбор активного уровня HIGH/LOW, включение, выключение и переключение из логики. У реле настраиваются напряжение и источник питания. [MOSFET](docs/mosfet.md), [реле](docs/relays.md).
- **Механические и сенсорные кнопки:** события нажатия и отпускания, проверка текущего состояния и защита от дребезга. Для цифровых сенсорных модулей настраивается активный уровень; редактор проверяет совместимость напряжений. [Сенсорные кнопки](docs/touch-button.md).
- **Шаговые двигатели:** NEMA 17 с драйверами TB6600, MKS TMC2208 V2 и DRV8825 для ESP32, ESP32-S3, ESP32-P4 и Arduino Nano. Движение в шагах или оборотах, непрерывное вращение, разгон, остановка и отключение удержания. Ток и микрошаг на драйвере настраиваются вручную. [Подключение и ограничения](docs/stepper.md).
- **Давление и температура XGZP6847D:** измерение по I²C, выбор питания и коэффициента K, запуск по событию или автоматически. Результаты можно отправить в Serial, на дисплей и в MQTT. Поддерживаются ESP32, ESP32-S3, ESP32-P4 и Arduino Nano. [Подключение и настройка](docs/xgzp6847d.md).
- **Температура микроконтроллера:** встроенный датчик ESP32-S3/P4, измерение по событию или автоматически, вывод на дисплей и в Serial, обработка ошибок. [Настройка и особенности измерения](docs/temperature.md).
- **Дисплеи:** редактор фона, текста, индикаторов состояний и PNG-изображений с прозрачностью. Доступны заставка при запуске, шрифты с кириллицей и предпросмотр экрана. Числа, текст, состояния и события из логики можно связать с элементами интерфейса. Поддерживаются ST7789 SPI и JD9365 MIPI-DSI через ESP-IDF и LVGL. [Подключение и редактор](docs/displays.md).
- **Wi-Fi и Ethernet:** DHCP или статический IPv4, состояние подключения, IP-адрес, маска, шлюз и DNS. Wi-Fi поддерживается на ESP32, ESP32-S3 и ESP32-P4 Nano; на P4 используется ESP32-C6. Для Ethernet доступны W5500 SPI и IP101/RMII. Блок проверки интернета проверяет выбранный HTTP/HTTPS-ресурс с заданными интервалом и таймаутом. [Wi-Fi](docs/wifi.md), [сеть и индикаторы](docs/network.md).
- **Wi-Fi маршрутизатор:** подключение к интернету через Ethernet или Wi-Fi, раздача по Wi-Fi или Ethernet, IPv4 NAPT, DHCP, локальный DNS и резервное подключение. Поддерживаются ESP32-S3 и ESP32-P4 Nano через ESP-Hosted. Доступны локальное управление с аутентификацией и обновление прошивки по сети. [Возможности и ограничения](docs/router.md), [пример ESP32-S3-ETH с дисплеем](examples/router-esp32-s3-eth-test.clex.json).
- **ESP-NOW для ESP32/ESP32-S3:** обмен сообщениями и командами, подтверждение выполнения, шифрование, режимы Normal/Long Range и статистика передачи. Можно сохранять выбранный режим после отключения питания и отслеживать доступность устройств, потерю связи и актуальность RSSI. [Настройка](docs/espnow.md), [сохранение режима](docs/espnow-persistence.md), [контроль связи](docs/espnow-health.md).
- **MQTT 3.1.1 и 5.0:** подключение к брокеру через Wi-Fi или Ethernet, TLS с проверкой сертификата, QoS 0/1/2, LWT, сессии и восстановление подписок. Доступны несколько подключений, отправка и получение текстовых и двоичных сообщений, свойства MQTT 5. [Настройка и ограничения](docs/mqtt.md).
- **Голосовое управление ESP32-P4/S3:** настройка команд и фразы активации, запись примеров через встроенный или внешний микрофон, подготовка моделей в приложении. Распознавание работает локально на плате; действия для команд назначаются в «Логике». Для звукового подтверждения можно воспроизвести запись. [Подготовка и ограничения](docs/voice.md), [внешние микрофоны](docs/microphones.md).
- **Звук и камера ESP32-P4:** звуковой сигнал через ES8311/I2S, захват кадров OV5647/CSI, события результата и диагностика. Монтаж учитывает используемые контакты и конфликты ресурсов.
- **Инструменты разработки:** поиск существующих установок ESP-IDF и Arduino AVR, выбор окружения и папки для новых инструментов. Приложение показывает объём загрузки и устанавливает недостающие пакеты после подтверждения. Существующие внешние установки сохраняются. [Управление ESP-IDF](docs/sdk-manager.md).
- **Сборка и запись прошивки:** просмотр сгенерированных исходников, сборка через ESP-IDF или Arduino CLI, журнал компилятора, обнаружение USB-портов и запись собранной прошивки. Для обмена сообщениями с платой доступен последовательный монитор: обычно 115200 бод, для голосового компонента – 460800 бод.

Редактор работает локально, без регистрации и облачного сервиса. Приложение не отправляет телеметрию.

## Монтаж

Выберите плату, добавьте компоненты и соедините их физические контакты. Редактор проверяет допустимость GPIO, конфликты, питание и параметры компонентов.

![Монтаж ESP32-S3-ETH](docs/images/assembly.png)

## Визуальная логика

Соедините событие с нужным действием: например, нажатие кнопки с переключением светодиода или такт таймера с увеличением счётчика. Данные сетевых блоков и датчиков можно вывести на дисплей через «Подключить данные». Все соединения сохраняются в проекте.

![Граф логики с сетевыми данными в CLEX Flow](docs/images/logic.png)

## Дисплеи

Дважды нажмите на блок «Экран дисплея», чтобы открыть редактор интерфейса. Сохранённый экран включается в прошивку. Поддерживаются TFT SPI 240×320 на ST7789 и Waveshare 10.1-DSI-TOUCH-A 800×1280 на JD9365 с сенсорной панелью GT9271.

![Редактор экрана с кириллицей](docs/images/display-editor.png)

Подробнее: [подключение, шрифты и расширение библиотеки](docs/displays.md).

## Платформы

Установщики доступны для **macOS Apple Silicon (ARM64)** в формате `.dmg` и **Windows x64** в формате `.exe`.

Сборка прошивок поддерживается для **ESP32**, **ESP32-S3**, **ESP32-P4** и **Arduino Nano ATmega328P/CH340G**. Для ESP32 нужна **ESP-IDF 5.4.4**; другие версии SDK пока не поддерживаются.

В каталоге есть следующие платы:

- ESP32 DevKit V1 (30 pin), ESP32-WROOM-32: 4 МБ Flash, UART через USB-UART. [Распиновка, совместимость и прошивка](docs/esp32-devkit-v1.md).
- Waveshare ESP32-S3-ETH.
- Espressif ESP32-S3-DevKitC-1 v1.1 N8R8.
- Arduino Nano ATmega328P/CH340G с USB Type-C: Arduino AVR Boards 1.8.6, обычный и старый загрузчик, GPIO, таймер, счетчик, секундомер, Serial и шаговые двигатели. [Подготовка и первый проект](docs/arduino-nano.md).
- ESP32-P4-NANO от Waveshare, включая плату из комплекта KIT-C. Сборка RISC-V, консоль UART через USB-C, GPIO, SPI-дисплей и встроенный Ethernet IP101/RMII. Ревизия ESP32-P4 выбирается в свойствах платы.

Распиновка и встроенные интерфейсы P4: [ESP32-P4-NANO](docs/esp32-p4-nano.md).

В дальнейшем планируется добавить другие семейства ESP, модели Arduino и платы Raspberry Pi.

Для ESP32 DevKit V1 проверена запись прошивки через USB-UART. Работа отдельных периферийных устройств на этой плате ещё не проверена.

На Waveshare ESP32-S3-ETH, ESP32-P4-NANO и Arduino Nano проверены запись прошивки и отдельные рабочие сценарии. На двух ESP32-S3 проверены обмен по ESP-NOW и переключение Normal/Long Range. На ESP32-S3-ETH проверена раздача интернета с W5500 на Wi-Fi-клиентов и вывод температуры кристалла на дисплей. Драйверы дисплея DSI и сенсорной панели P4, звука ES8311 и камеры OV5647 компилируются, но их работа на оборудовании ещё не проверена. Перед подключением сверяйте модель, ревизию и монтаж с документацией производителя.

## Установка

Откройте [GitHub Releases](https://github.com/proxymades/clex-flow/releases) и скачайте установщик предварительной версии для своей системы.

### macOS Apple Silicon

1. Скачайте файл `.dmg` для ARM64, откройте его и перенесите **CLEX Flow** в **Applications / Программы**.
2. Запустите приложение из папки **Программы**.
3. Если macOS блокирует первый запуск, откройте **Системные настройки → Конфиденциальность и безопасность** и разрешите запуск CLEX Flow кнопкой **Все равно открыть**. Разрешайте запуск только файла, скачанного из репозитория проекта.

Приложение пока не подписано сертификатом Developer ID и не прошло нотариализацию Apple. Для запуска на ARM64 используется локальная подпись ad-hoc. Подробнее: [Tauri](https://v2.tauri.app/distribute/sign/macos/#ad-hoc-signing), [инструкция Apple](https://support.apple.com/102445).

### Windows x64

1. Скачайте NSIS-установщик `.exe` и запустите его.
2. Следуйте шагам установки и откройте **CLEX Flow** из меню **Пуск**.
3. При предупреждении SmartScreen проверьте источник файла. Для доверенного установщика выберите **Подробнее → Выполнить в любом случае**, если эта возможность доступна. На рабочем компьютере может потребоваться разрешение администратора.

Установщик не подписан сертификатом издателя. Для интерфейса нужен Microsoft Edge WebView2 Runtime; установщик Tauri проверяет его наличие. ESP-IDF и компиляторы устанавливаются отдельно. Приложение может найти уже установленные инструменты или помочь установить недостающие.

## Папка проектов

В десктопном приложении откройте **Настройки → Хранилище проектов → Выбрать папку**. Можно выбрать папку на другом доступном диске независимо от места установки CLEX Flow.

Приложение сохранит текущие правки и скопирует проекты в выбранную папку. Исходные файлы останутся в прежнем каталоге как резервная копия. Файлы с одинаковыми именами и разным содержимым не заменяются: выберите другую папку. Выбранный путь сохраняется после перезапуска и обычного обновления приложения. При недоступном диске приложение сообщает об ошибке; подключите диск перед продолжением работы.

## Совместимость проектов

Проекты сохраняются в формате 4. При открытии проектов форматов 1-3 приложение преобразует их и сохраняет резервную копию оригинала. Связи, требующие ручной замены, остаются на схеме с предупреждениями.

Совместимые обновления блоков не требуют их замены. При несовместимом изменении старый блок и его соединения сохраняются, а предупреждение объясняет причину. Добавьте актуальный блок рядом, настройте его и восстановите соединения, затем удалите старый. До замены несовместимых блоков сборка недоступна. [Подробнее о версиях блоков](docs/logic.md#версии-блоков).

## Запуск для разработки

Нужны **Node.js 22.12+**, npm и Rust. На macOS также нужны Xcode Command Line Tools; на Windows – Build Tools for Visual Studio с инструментами C++ и WebView2. Для работы с редакторами ESP-IDF не нужна. Для сборки прошивок ESP32 установите **ESP-IDF 5.4.4** или выберите существующую установку в разделе «Инструменты разработки».

```sh
git clone https://github.com/proxymades/clex-flow.git
cd clex-flow
npm ci
npm run desktop
```

Сборка приложения:

```sh
npm run desktop:build
```

Результат на macOS: `src-tauri/target/release/bundle/macos/CLEX Flow.app`. Для установщиков `.dmg` (macOS) и `.exe` (Windows) используйте отдельные конфигурации и команды из [руководства по выпуску версий](docs/releases.md).

Для веб-предпросмотра запустите `npm run dev` и откройте `http://127.0.0.1:1420`. В браузере проекты хранятся в localStorage; десктопная версия использует файловое хранилище. Скриншоты показывают интерфейс с демонстрационным проектом.

## Проверки

Тесты отображения загрузки инструментов требуют Python 3.9+ (`python3` или `python`). ESP-IDF для этих тестов не нужна.

```sh
npm run lint
npm test
npm run build
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo test --manifest-path src-tauri/Cargo.toml --locked
npm run test:firmware-parity
```

`test:firmware-parity` сравнивает файлы генератора JavaScript и нативного слоя Rust для поддерживаемых конфигураций ESP32/S3/P4/Nano, включая ESP-NOW, маршрутизатор, шаговые двигатели и измерение температуры. Для этой проверки не нужны ESP-IDF, сетевое подключение или плата. Сначала выполните Rust-тесты, чтобы подготовить зависимости.

UI-сценарии используют Playwright: `test:ui`, `test:assembly-ui`, `test:logic-ui`, `test:firmware-ui`. Запускайте их при работающем веб-предпросмотре и установленном Chromium. Для P4 и новых маршрутов доступны `test:p4-ui`, `test:peripheral-ui`, `test:manual-routing-ui`. URL предпросмотра задается через `CLEX_PREVIEW_URL`, путь Chromium при необходимости – через `CLEX_BROWSER_EXECUTABLE`. Результаты сохраняются локально в `.artifacts/`.
