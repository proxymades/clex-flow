JS-тесты проверяют создание/сериализацию, уникальность ID, неверные поля, версии, размер UTF-8, защиту схем будущих этапов, сохранение дополнительных полей и сортировку. Rust-тесты проверяют защиту путей, соответствие ID, лимит размера и атомарную замену файла.

UI-сценарий проверяет создание, сохранение и перезагрузку, отмену/отказ от несохранённых изменений, экспорт и импорт копии, переименование, поиск, подтверждение удаления и результат после перезагрузки, отклонение неподдерживаемого JSON. Снимки просмотрены при 1440×940 и 1000×700; при минимальной ширине страницы горизонтального переполнения нет. Для проверки использован уже установленный Chromium через аргумент пути к исполняемому файлу, без загрузки нового браузера:

```sh
npm run test:ui -- ~/Library/Caches/ms-playwright/chromium_headless_shell-1243/chrome-headless-shell-mac-arm64/chrome-headless-shell
```

Нативные действия проверялись отдельно от веб-предпросмотра. Созданы два проверочных локальных проекта: `Blink Test` и `Blink Test (проверка импорта)`. Они доступны в библиотеке приложения. Проверочный экспорт и снимки UI находятся в `.artifacts/`, исключённом из Git.

При нативной проверке исправлены недостающее разрешение завершения окна и обработка выхода через стандартный пункт меню. Совместимая JS API Tauri зафиксирована на 2.10.1. Повторная нативная сборка и сценарий выхода выполнены после исправлений.

## Ограничения

- Это рабочий **первый этап**, а не законченная визуальная среда программирования.
- Выбирается только целевая платформа ESP32-S3. Конкретной модели, SVG-платы с контактами и проверенной распиновки пока нет.
- Монтаж, GPIO, аппаратные компоненты, React Flow, типизированные связи, Undo/Redo графа и его автосохранение не реализованы. Сохранение свойств сейчас ручное.
- Загрузчик модулей, проверка их совместимости и реализации генератора ещё не существуют. Документ формата модулей – проект будущего контракта.
- Генератор прошивки, ESP-IDF-процессы, отмена сборки, последовательные порты, прошивка и монитор не реализованы; кнопки отключены и этапы подписаны.
- Установка ESP-IDF 5.4.4 подтверждена только по исходникам и `export.sh`. Работоспособность toolchain не проверена.
- **Физическая плата, LED, GPIO, сборка и прошивка не проверялись.** Blink Test на оборудовании остаётся критерием этапа 5.
- Windows и Linux не запускались и не собирались. Есть переносимые Tauri/React-исходники, но их нельзя считать проверенной поддержкой этих ОС. Типы установщиков нужно настроить отдельно.
- Выполнена отладочная `.app`-сборка. Release-сборка, подпись Developer ID и нотариализация Apple не проверены и не настроены для распространения.
- Нет блокировки нескольких экземпляров, восстановления удалённого проекта, резервных копий и миграций формата. Не проверялась устойчивость при аварийном отключении питания или принудительном завершении ОС.
- Веб-предпросмотр использует localStorage; native-данные и browser-данные не синхронизируются.
- История журнала между запусками пока не сохраняется; нижняя панель показывает состояние текущего проекта.

Исходники других проектов, ESP-IDF и его конфигурация не изменялись. Публикация в GitHub не выполнялась.
