## Реальная компиляция

Использован существующий полный SDK `~/.espressif-s3/v5.4.4/esp-idf` и Python `~/.espressif/tools/python/v5.4.4/venv/bin/python`. SDK не обновлялся и не переустанавливался. Auto-init submodules и компонентные загрузки отключены.

Журналы отдельных compiler-проверок: `.artifacts/idf-blink-eim-build.log`, `.artifacts/idf-all-blocks-build.log`. Расширенный граф собран с кодом выхода 0, app size 0x2cf90. Созданы bootloader, partitions, `.elf` и `.bin`.

Нативная студия создала отдельный проект:

```text
~/Library/Caches/kz.clex.flow/firmware/
00c3f8fa2f3c6a86126158de60c3248f1d7abfd01d1eebd59e3910453ed19c90-4dc7f6b3c050/
```

Сборка запускается кнопкой «Собрать». Проверены реальный журнал, отмена и повторное выполнение. После успеха показана актуальность firmware; запись и монитор недоступны при отсутствии выбранного порта. Существующие проекты пользователя не переписывались ради интеграции.

## Границы доказательства

- Физическая ESP32-S3-ETH не подключена. Видны только исключённые системные Bluetooth/debug порты.
- Esptool-запись, pyserial на физическом устройстве, GPIO16/17, debounce и мигание LED **не проверены аппаратно**. Реализация готова к отдельным испытаниям этапа 5.
- Ревизия платы и правильность конкретного монтажа не подтверждены. Требуются внешние LED/резистор и соответствующий профиль/порт.
- Монитор только читает, 115200 бод. Нет ввода команд, GDB, декодирования backtrace, переподключения и полного постоянного архива логов.
- Flash требует успешную сборку в текущем сеансе. GUI не выбирает первый подключённый порт автоматически.
- Runtime графа имеет один worker, ограниченную очередь; это небольшой цифровой эксперимент, не hard-real-time система. Не поддерживаются циклы, условия, счётчики, дисплеи или Ethernet-модули.
- Windows/Linux, release-оптимизация, подпись Developer ID, нотариализация и `.dmg` пока не проверены. Поставлена запускаемая debug `.app`.
- Нет межпроцессной блокировки между несколькими экземплярами студии, восстановления удалённых проектов, автоустановки SDK и исполняемых пользовательских модулей.
- Git, коммиты, теги, GitHub и публикации Releases на этом этапе не выполнялись.

При последней визуальной проверке найдено исчезновение линий в WebKit после пересоздания controlled nodes. React Flow сбрасывает handleBounds, если поле measured отсутствует. Runtime-узлы теперь сохраняют объект measured до завершения измерения, без выдуманных размеров; данные проекта не меняются. Повторные lint, сборка `.app`, browser-сценарий логики и нативное открытие/компиляция показали три линии.
