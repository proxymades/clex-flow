# Температура микроконтроллера

Блок «Температура микроконтроллера» в категории «Диагностика» считывает встроенный датчик кристалла ESP32-S3 или ESP32-P4 через драйвер `esp_driver_tsens` ESP-IDF 5.4.4. Отдельный компонент в монтаже и провода не нужны. На Arduino Nano блок недоступен.

По умолчанию измерение выполняется при запуске, затем раз в секунду. Период настраивается от 250 мс. Для измерения по событиям отключите автоматический опрос и подключите событие к входу «Измерить». Несколько блоков используют один экземпляр физического датчика; все обращения выполняются последовательно в рабочей задаче графа.

Для экрана создайте динамический текст типа «Текст» и соедините выход «Температура с единицей» с этим элементом. Автоматическое подключение данных добавляет событие обновления. Выход содержит число с одним десятичным знаком и `°C`; при ошибке он содержит «Нет данных». Выход «Показание достоверно?» показывает результат последней попытки, а «Ошибка датчика» передает описание ошибки SDK. Для вычислений используйте числовой выход и событие «Температура получена»: при неудаче число сбрасывается в NaN и событие успеха не отправляется.

Драйвер устанавливается с начальным диапазоном -10-80 °C. ESP-IDF 5.4.4 автоматически переключает внутренний диапазон при выходе показания за его границы. Пределы измерения датчика не являются допустимыми рабочими температурами устройства.

Датчик показывает температуру внутри кристалла с погрешностью, а не температуру воздуха или поверхности корпуса. Показание помогает наблюдать нагрев и сравнивать режимы работы, но не определяет само по себе, безопасен ли нагрев конкретной платы. На ESP32-S3-ETH проверено отображение показаний на дисплее. Для P4 и других аппаратных конфигураций требуется отдельная проверка.

Описание API: [ESP32-S3](https://docs.espressif.com/projects/esp-idf/en/v5.4.4/esp32s3/api-reference/peripherals/temp_sensor.html), [ESP32-P4](https://docs.espressif.com/projects/esp-idf/en/v5.4.4/esp32p4/api-reference/peripherals/temp_sensor.html).
