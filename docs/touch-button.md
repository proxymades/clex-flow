# Сенсорная кнопка

Универсальный аппаратный компонент `clex.hardware.touch-button` версии **1.0.0** для емкостных модулей с готовым цифровым выходом. Производитель и микросхема не определяют генерацию. Встроенные сенсорные площадки ESP32 без внешнего цифрового модуля сюда не относятся.

## Подключение

Добавьте **Сенсорную кнопку** в «Монтаже»:

- **VCC** – питание 3,3 или 5 В, выбранное по документации конкретного модуля. Подключение к другому напряжению платы отклоняется.
- **GND** – общая земля.
- **OUT** – свободный цифровой вход GPIO.

В свойствах укажите фактическое напряжение HIGH на OUT. Напряжение питания модуля и допустимый уровень GPIO – разные характеристики. Для ESP32 проверка отклоняет OUT выше 3,3 В. Питание 5 В допустимо при прямом подключении к ESP32 только для модуля, который действительно обеспечивает выход 3,3 В; выбор значения в программе не понижает физическое напряжение. Для модуля с выходом 5 В нужен внешний согласователь уровней, который текущий компонент отдельно не моделирует. Комбинация OUT выше VCC отклоняется.

Поддерживаемые варианты питания не означают, что любой сенсорный модуль допускает оба напряжения. Сверьте характеристики своего изделия. Например, официальный каталог [Tontek](https://www.tontek.com.tw/product/product2?idx=243&lang=) указывает диапазон питания TTP223-BA6 2,0-5,5 В; характеристики готовой платы могут отличаться. Допустимые уровни ESP32 приведены в [даташите Espressif](https://www.espressif.com/sites/default/files/documentation/esp32-s3_datasheet_en.pdf).

## Логика

В группе сенсорной кнопки доступны:

- **События кнопки:** «Кнопка нажата» и «Кнопка отпущена».
- **Проверить кнопку:** по входному сигналу выдаёт одно из событий текущего состояния.

Активный уровень HIGH/LOW задаётся в «Монтаже». Активное состояние соответствует выбранному уровню OUT. Фильтр в миллисекундах требует устойчивого изменения; 0 отключает задержку. Начальное состояние запоминается без ложного события нажатия, удержание не создаёт повторных событий. При переключаемом выходе сенсорного модуля событие соответствует изменению OUT, а не каждому физическому касанию.

Пример: «Кнопка нажата» → «Прибавить 1» счётчика. Таймер для наблюдения за изменениями не нужен.

## Реализация и проверки

Компонент использует опрос цифрового входа, фильтр, блоки чтения/изменения и GPIO-генерацию ESP-IDF/Arduino AVR. Отдельный драйвер сенсорной микросхемы не требуется. Для сенсора внутренняя подтяжка отключена; механическая кнопка использует подтяжку вверх.

Общие расширения каталога: `terminal.voltageParameter` получает напряжение питания из свойства компонента; `constraints.signalVoltageParameter` / `supplyVoltageParameter` позволяют проверять уровни OUT и VCC. Прежнее фиксированное `terminal.voltage` продолжает работать. Чтение GPIO выбирает компонент по возможности цифрового входа, а не по идентификатору механической кнопки.

Программные тесты охватывают HIGH/LOW, VCC/GND/OUT, несовместимые напряжения, сохранение/открытие и интерфейс. Исполнение сгенерированного Arduino AVR-кода проверяет фильтрацию импульсов, одиночное событие при удержании, деактивацию, счетчик и чтение состояния. Генерация ESP32-S3 и ESP32-P4 проверяется отдельно.

Команды проверки: `npm test`, `npm run lint`, `npm run test:nano-runtime`, `npm run test:touch-button-ui`.
