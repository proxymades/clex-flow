# Сохранение режима ESP-NOW

В «Монтаже» выберите компонент ESP-NOW и включите **«Запоминать режим передачи после перезагрузки»**. Как и другие настройки прошивки, изменение применяется после сборки и прошивки платы.

По умолчанию настройка выключена. Проекты, сохраненные без этого параметра, также считают ее выключенной.

| Настройка | При включении питания |
|---|---|
| Выключена | Применяется начальный режим из проекта |
| Включена, запись существует | Восстанавливается последний сохраненный режим |
| Включена, записи еще нет | Применяется начальный режим из проекта |

Режим хранится в NVS самой ESP32 и относится только к этой плате. Запись привязана к ID проекта и экземпляра ESP-NOW. Переименование проекта, перемещение узлов и изменение peers не сбрасывают выбранный режим. Другой проект или новый экземпляр компонента не подхватывает чужую настройку. Формат проекта остается прежним; версии ESP-NOW остаются 2.0.0.

Любая успешная установка режима через блок управления использует одну реализацию сохранения. Источником события может быть кнопка, таймер, полученная команда или другая логика. Уже сохраненное значение повторно не записывается. При запуске чтение само по себе не создает запись.

Выключенная галочка игнорирует сохраненный режим, но не удаляет запись. После повторного включения и прошивки прежний сохраненный режим может восстановиться. Полное стирание памяти платы удаляет сохранение.

## Ошибки

Ошибка чтения или недействительная запись отображается через состояние радио; используется начальный режим, если радио удалось запустить. Данные NVS автоматически не стираются. Ошибка инициализации NVS, как и раньше, может остановить запуск радио.

При ошибке записи радио уже может работать в новом режиме. Выход состояния показывает фактический режим, а блок управления выдает событие «Ошибка установки режима» и причину «Режим установлен, но не сохранен». Положительное подтверждение команды по ветви «Режим установлен» при этом не отправляется. Повторная команда того же режима повторит сохранение. Ошибка сохранения не исчезает из состояния радио только из-за успешной передачи другого пакета.

Эта настройка не синхронизирует несколько плат. Если требуется менять режим группы, соответствующие команды и подтверждения остаются частью графа проекта.

## Подтверждения обмена

ACK (*acknowledgement*) означает подтверждение приема сообщения или выполнения команды. «Без ACK» / «Без подтверждения» считает обмены, для которых после повторов не пришло необходимое подтверждение. Это накопительный счетчик с запуска платы, а не процент потерь отдельных радиопакетов. Отрицательное подтверждение выполнения команды отображается как ошибка, но не считается отсутствующим ACK.

Используется штатный [API NVS ESP-IDF 5.4.4](https://docs.espressif.com/projects/esp-idf/en/v5.4.4/esp32s3/api-reference/storage/nvs_flash.html). Пользователь подтвердил работу ESP-NOW на физических платах. Программные тесты дополнительно моделируют перезапуск, поврежденные записи и ошибки чтения/сохранения.
