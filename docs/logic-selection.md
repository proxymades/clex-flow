# Выбор по значению

Блок «Выбор по значению» принимает данные и сигнал «Выбрать действие». В настройках выбирается тип: **Число**, **Текст** или **Да/Нет**.

Для чисел и текста добавьте от 1 до 16 вариантов. Каждый вариант создаёт выход события. По сигналу блок читает последнее значение источника и запускает один выход совпавшего варианта. Если совпадений нет, срабатывает «Другое значение».

- **Число:** разные целые значения от -2147483648 до 2147483647. Сравнение точное.
- **Текст:** разные строки до 256 байт UTF-8. Регистр и пробелы учитываются; пустая строка тоже может быть вариантом.
- **Да/Нет:** значение true запускает выход «Да», false запускает «Нет». Дополнительные варианты и выход «Другое значение» не нужны.

Например, для MQTT можно задать строки ON, OFF, GROUP ON и GROUP OFF. Соедините «Получено» с «Выбрать действие», а «Текст сообщения» с «Текущее значение». Выходы вариантов подключаются к управлению нагрузкой, отправке MQTT или другим действиям.

Обновление данных само по себе не запускает выбор. Вход читает последнее значение независимо от события его обновления. До первого обновления используется начальное значение источника.

Изменение значения варианта сохраняет его подключение. Удаление варианта удаляет его связи. При смене типа данных вход данных и выходные ветви нужно подключить заново; вход «Выбрать действие» сохраняется. Изменение настроек вместе со связями можно отменить.

Блок имеет версию 2.0.0. В проектах с версией 1.x старый блок и его связи остаются на схеме с предупреждением. До сборки добавьте новый «Выбор по значению», задайте варианты и восстановите нужные соединения, затем удалите старый блок. Настройки прежней версии автоматически не преобразуются.

Поддерживаются ESP32, ESP32-S3, ESP32-P4 и Arduino Nano. На Nano целочисленное сравнение сохраняет точность больших счётчиков, а строки вариантов хранятся во Flash.

## Переключение пары ESP-NOW

На передатчике выход режима из «Управление ESP-NOW → Следить за состоянием» подключается к числовому входу выбора, а событие удержания сенсора к входу действия. Для значений 0 и 1:

- 0 (Normal) запускает отправку команды SET_LR;
- 1 (Long Range) запускает отправку команды SET_NORMAL.

Приёмник устанавливает указанный режим и подтверждает результат. Передатчик меняет свой режим после подтверждения выполнения соответствующей команды. Отпускание сенсора не запускает переключение. Значение ошибки режима 2 не подключается к командам.

Передаются явные целевые режимы, поэтому повтор той же команды не переключает приёмник обратно. Потеря подтверждения или ошибка локальной настройки может оставить платы в разных режимах; состояние и ошибки радио нужно проверять отдельно. Перезапуск возвращает плату к начальному режиму из настроек ESP-NOW.
