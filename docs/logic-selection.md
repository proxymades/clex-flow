# Выбор по значению

Блок `clex.logic.select-number` версии `1.0.0` доступен для ESP32-S3, ESP32-P4 и Arduino Nano. Он принимает сигнал «Выбрать действие» и число «Текущее значение».

В свойствах задаются два разных целых числа. При сигнале блок читает последнее значение источника и запускает ровно один выход:

- «Значение …» для первого совпадения;
- «Значение …» для второго совпадения;
- «Другое значение», если совпадений нет.

Обновление числа само по себе не запускает выбор. Для этого входа не требуется вести событие обновления от источника: можно, например, читать состояние радио по событию сенсора. До первого обновления используется начальное значение, заданное реализацией источника. У остальных блоков прежние проверки порядка событий и данных сохраняются.

Настраиваемые значения лежат в диапазоне от -2147483648 до 2147483647. Сравнение точное: дробное число, NaN и бесконечность не совпадают с целыми настройками и идут в «Другое значение». Nano сохраняет целочисленное сравнение без потери точности больших счетчиков.

## Переключение пары ESP-NOW

На передатчике выход режима из «Управление ESP-NOW → Следить за состоянием» подключается к числовому входу выбора, а событие удержания сенсора – к входу действия. Для значений 0 и 1:

- 0 (Normal) запускает отправку команды `SET_LR`;
- 1 (Long Range) запускает отправку команды `SET_NORMAL`.

Приемник устанавливает указанный режим и подтверждает результат. Передатчик меняет свой режим после подтверждения выполнения соответствующей команды. Отпускание сенсора не запускает переключение. Значение ошибки режима 2 не подключается к командам.

Передаются явные целевые режимы, поэтому повтор той же команды не переключает приемник обратно. Потеря подтверждения или ошибка локальной настройки все же может оставить платы в разных режимах; состояние и ошибки радио нужно проверять отдельно. Перезапуск возвращает плату к начальному режиму из настроек ESP-NOW.
