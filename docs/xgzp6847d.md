# Датчик XGZP6847D

Компонент CFSensor XGZP6847D измеряет давление и температуру по I²C. Поддерживается протокол с адресом `0x6D`, регистром команды `0x30` и данными `0x06-0x0A`, описанный в документации XGZP6847D V2.8. Серия **XGZP6847DC с адресом `0x58` не поддерживается**: у неё другой набор регистров и формулы. Изменение адреса не делает эти серии совместимыми.

| Плата | Подключение I²C |
| --- | --- |
| ESP32 DevKit V1 WROOM-32, 30 pin | Два аппаратных контроллера, свободные GPIO с входом и выходом |
| ESP32-S3 DevKitC-1 | Два контроллера, свободные GPIO |
| Waveshare ESP32-S3-ETH | Два контроллера, GPIO с учётом занятости камерой и встроенной периферией |
| Waveshare ESP32-P4 Nano | Два контроллера; совместимую шину можно разделять со встроенной периферией при совпадении SDA/SCL |
| Arduino Nano ATmega328P | Один контроллер Wire: A4/SDA, A5/SCL |

## Версии датчика

| Документация | Адрес I²C | Протокол | Поддержка в CLEX Flow |
| --- | --- | --- | --- |
| V2.8 | `0x6D` | Команда `0x30 = 0x0A`, давление `raw / K`, температура `raw / 256` | Реализована |
| V3.x (новая серия) | `0x58` | Другие регистры, команды и калибровочные формулы | Не поддерживается |

Автор Arduino-библиотеки отдельно указывает несовместимость с протоколом V3.x. Версия библиотеки и версия протокола датчика – разные обозначения. Для выбора драйвера сверяйте адрес I²C и документацию исполнения.

## Настройка монтажа

Добавьте **XGZP6847D** из категории «Датчики». Подключите VDD, GND, SDA и SCL, выберите контроллер I²C и коэффициент K. На одной шине может находиться один XGZP6847D с фиксированным адресом `0x6D`. Второй датчик на ESP32 требует другого контроллера и другой пары GPIO. Несколько логических блоков могут обращаться к одному датчику.

Питание датчика и подтяжки SDA/SCL должны соответствовать логике платы: **на ESP32 разрешены только 3,3 В, на Arduino Nano ATmega328P – 5 В**. Используйте исполнение датчика, допускающее это напряжение. В настройках доступен только совместимый вариант питания; несовместимые контакты питания нельзя соединить с VDD. Проверка сохранённого проекта также блокирует сборку при неправильном питании или соединении. Подключение через преобразователь уровней этим компонентом не моделируется и не отменяет ограничения.

По документации обычной серии внешние подтяжки SDA/SCL составляют около 4,7 кОм. Они могут быть установлены на модуле. Внутренние подтяжки ESP32 не заменяют подбор внешних подтяжек. Частота обмена – 100 кГц.

Корпус DIP6 содержит шесть выводов. В компоненте показаны все выводы, а NC недоступны для соединения.

| Вывод | Назначение |
| --- | --- |
| 1 | SCL |
| 2 | NC – не подключать |
| 3 | GND |
| 4 | VDD |
| 5 | SDA |
| 6 | NC – не подключать |

Чертёж и назначение выводов приведены на странице 3 спецификации XGZP6847D V2.8. Нумерацию сверяйте с индексом первого вывода. Иллюстрация в компоненте показывает один штуцер и шесть контактов; расположение на готовой плате модуля может отличаться.

## Коэффициент пересчёта

K зависит от исполнения датчика и выбирается по наибольшему абсолютному давлению относительно нуля. Для диапазонов −100…100, −100…0 и 0…100 кПа это 100 кПа, K = 64. Для −100…300 кПа это 300 кПа, K = 16. Выбор K обязателен перед сборкой; сверяйте коэффициент с паспортом исполнения.

| Максимальное абсолютное давление P, кПа | K |
| --- | --- |
| P < 1 | 8192 |
| 1 ≤ P < 2 | 4096 |
| 2 ≤ P ≤ 4 | 2048 |
| 4 < P ≤ 8 | 1024 |
| 8 < P ≤ 16 | 512 |
| 16 < P ≤ 32 | 256 |
| 32 < P ≤ 65 | 128 |
| 65 < P ≤ 130 | 64 |
| 130 < P ≤ 260 | 32 |
| 260 < P ≤ 500 | 16 |
| 500 < P < 1000 | 8 |
| P ≥ 1000 | 4 |

Таблица коэффициентов не означает, что любой XGZP6847D рассчитан на все перечисленные давления. Рабочий диапазон определяется конкретным датчиком. Например, для исполнения −100…300 кПа с K = 16 выбирается коэффициент 16. Давление вычисляется из знакового 24-битного отсчёта как `raw / K` в паскалях; температура – из знакового 16-битного отсчёта как `raw / 256` в °C.

## Блок измерения

Добавьте **XGZP6847D – Измерение** и выберите датчик из монтажа. Автоматический опрос включён по умолчанию раз в секунду, минимальный период – 100 мс. Для ручного измерения отключите автоматический опрос и подключите событие ко входу «Измерить».

Выходы: давление в выбранной единице (Па, кПа, бар, мм рт. ст. или PSI), давление в Па, температура в °C, тексты с единицами, достоверность и ошибка. Числовые данные обрабатываются по событию «Данные получены». Событие «Измерение завершено» отправляется и при ошибке, чтобы обновить экран сообщением «Нет данных». Числа при ошибке сбрасываются в NaN, событие успеха не отправляется. «Ошибка измерения» позволяет отдельно обработать отказ.

Данные доступны обычным связям логики: на дисплей, в Serial или MQTT. На Nano дробные показания выводятся в Serial через форматирование датчика; поддержка дисплеев и MQTT для Nano этим компонентом не добавляется.

Преобразование выполняется асинхронно в рабочем цикле графа. Драйвер проверяет готовность, ограничивает ожидание 100 мс и сообщает ошибки записи, чтения и таймаут преобразования. Следующее автоматическое или ручное измерение повторяет обращение к датчику. Запросы нескольких блоков во время одного преобразования используют его общий результат, сохраняя отдельные выходные значения и единицы каждого блока.

Датчик предназначен для воздуха и неагрессивных газов. Температура относится к самому датчику. Температурная компенсация и допустимое давление определяются паспортом исполнения.

## Реализация и проверка

Изучена [Arduino-библиотека XGZP6897D Francis Sourbier](https://github.com/fanfanlatulipe26/XGZP6897D). Её драйвер поддерживает протокол `0x6D`; совместимость с новой серией `0x58` автор отдельно исключает. В CLEX Flow реализован собственный драйвер по протоколу производителя: ESP-IDF 5.4.4 использует `i2c_master`, Arduino AVR 1.8.6 – `Wire`. Внешняя библиотека для сборки не требуется.

Проверены знаковые и дробные показания, единицы давления, таймаут, ошибки I²C и восстановление, несколько блоков одного датчика, ограничения питания и контактов, сохранение настроек и генерация файлов через Tauri. Сборки ESP32, ESP32-S3 и ESP32-P4 выполнены ESP-IDF 5.4.4. Arduino-код выполнен на тестовом стенде с моделями Wire/Serial; сборка AVR-компилятором не проверена.

Источники: [документация старой серии CFSensor V2.5](https://www.endrich.com/Datenbl%C3%A4tter/Sensoren/XGZP6847D-Pressure-Sensor-V2.5.pdf), [Arduino-библиотека XGZP6897D с поддержкой семейства XGZP6847D](https://github.com/fanfanlatulipe26/XGZP6897D).

Ранее сохранённые проекты с первоначальным названием компонента автоматически открываются как XGZP6847D. Назначения GPIO, провода, параметры и пользовательские названия сохраняются.
