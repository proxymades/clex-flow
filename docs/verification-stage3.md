JS-тесты охватывают прежний формат/монтаж и новый граф. Проверены все четыре типа портов, направление, дубликаты, один вход, циклы, порядок событий перед данными, ссылки на GPIO, удалённые компоненты, несовместимые версии и параметры. Копирование пересоздаёт ID и переносит внутренние связи; удаление убирает зависимые связи и сохраняет аппаратные версии.

История проверена на группировку drag и параметров, сохранение камеры при Undo/Redo, сброс Redo новой правкой и лимит 80 шагов. Очередь записи проверена на строгий порядок, восстановление после ошибки и сохранение более свежих правок при подтверждении старого снимка.

## UI-сценарий

В отдельном временном browser-профиле импортирован монтаж формата 2. Его чтение/открытие логики не выполняло дополнительной записи. Затем:

- Добавлены таймер и переключение GPIO, выбран ранее смонтированный LED.
- Несовместимое «число → событие» отклонено.
- Настоящие порты React Flow соединены **перетаскиванием**; остальные связи – кликами по подписям.
- Граф автоматически сохранился в формате 3 с неизменным монтажом.
- Изменение интервала отменено и повторено; drag отменяется одним шагом.
- Выделение двух блоков, копирование/вставка с внутренней связью, дублирование через ⌘D и удаление через Delete проверены.
- Искусственная ошибка localStorage оставляет новый узел в редакторе; ручное сохранение после снятия ошибки восстанавливает запись.
- Диалог выхода приостанавливает автосохранение; «Не сохранять» действительно оставляет старый текст сообщения на диске.
- После полной перезагрузки страницы восстанавливаются три блока, три связи и параметры; история нового сеанса пустая.
- Проверен вид при 1440×1000 и 1000×700. Снимки `.artifacts/clex-flow-logic.png` и `clex-flow-logic-small.png` просмотрены.

Тесты запускались с установленным Chromium без загрузки дополнительного браузера:

```sh
npm run test:logic-ui -- ~/Library/Caches/ms-playwright/chromium_headless_shell-1243/chrome-headless-shell-mac-arm64/chrome-headless-shell
```

Для нативной проверки создан **новый** проект `Blink Logic – граф` из проверочного JSON. Существующие проекты пользователя не изменялись и не переписывались при загрузке. Испытание в Tauri отдельно подтверждает файловую запись, а не только работу browser localStorage.

После нативной проверки добавлено явное обновление геометрии портов через `useUpdateNodeInternals` при загрузке карточки. Это устраняет зависимость линий от первичного измерения после ленивой загрузки редактора. Выполнены повторная сборка, весь UI-сценарий графа и визуальная проверка после полного перезапуска в активированном окне WebKit: линии присутствуют. Запуск через инструмент в фоне может откладывать кадр до активации окна, что учитывалось при проверке.

## Ограничения этапа

- Граф редактируется и проверяется, но **не исполняется** на компьютере или микроконтроллере.
- Генератор C/ESP-IDF, сборка прошивки, прошивка, порты, монитор и работающий физический Blink остаются этапами 4/5. Их кнопки недоступны.
- Пять логических модулей содержат контракт и метаданные `firmware: not-implemented`; реализации генератора ещё нет. Нет универсального языка, циклов, условий, счётчиков или произвольного кода.
- У входа одна связь, выход допускает несколько; неявных преобразований типов нет. Изменение связи выполняется удалением/созданием, перетаскивание её конца не подключено.
- Автосохранение запускается изменением графа и записывает весь проект, включая другие текущие правки. Изменения только монтажа/свойств остаются ручными.
- История только для графа, до 80 шагов, без сохранения между сеансами. Буфер блоков внутренний, для текущего проекта; системный clipboard не меняется.
- Встроенная библиотека собирается из JSON исходников. Импорта пользовательских исполняемых модулей во время работы нет.
- Некорректный по правилам граф можно сохранить как черновик, но структурно повреждённые файлы отклоняются.
- Распиновка физической ESP32-S3-ETH и её ревизия остаются неподтверждёнными. SVG и схема не являются измерением подключённого устройства.
- **ESP-IDF не запускался/не изменялся. Плата, GPIO, LED и прошивка не испытывались.**
- Windows/Linux, release-сборка, подпись Developer ID и нотариализация не проверены. Межпроцессной блокировки и восстановления удалённых проектов нет.

Добавлена одна runtime-зависимость `@xyflow/react` 12.11.1. TypeScript, Redux, сервер, облако, регистрации и платных функций нет. Коммиты и публикация не выполнялись.
