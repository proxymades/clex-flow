# Подготовка публичного репозитория

Дата: 2026-10-09. Репозиторий: https://github.com/proxymades/clex-flow. Ветка: `main`. Версия приложения **0.1.0**. Этот отчёт относится к подготовке исходников и системы выпуска, а не к аппаратному этапу разработки.

## Git и история

До подготовки в CLEX Flow отсутствовал `.git`; доступной локальной истории коммитов не было. Проверка существующего GitHub-репозитория через SSH показала отсутствие refs; GitHub API подтвердил `private: false`. Нет исторических Git-коммитов, которым можно было бы назначить версии этапов.

Git инициализирован на `main`, `origin` настроен на `git@github.com:proxymades/clex-flow.git`. SSH авторизуется существующей учётной записью `proxymades`; SSH-ключи не создавались и не менялись. Имя/почта автора настроены только в этом репозитории: публичная GitHub noreply-почта вместо локального личного адреса. Глобальные настройки не изменены.

Первый настоящий коммит фиксирует текущее состояние 0.1.0 вместе с подготовкой публикации. Отчёты этапов 1-4 сохранены как техническая история; промежуточные коммиты/версии не выдумываются. Force push, объединение несвязанных историй и переписывание коммитов не применяются. Тег и Release v0.1.0 не создаются.

## Безопасность

Использован официальный Gitleaks **8.30.1**, архив проверен по опубликованной SHA-256. Проверяются исходники/локальные файлы и перед отправкой вся имеющаяся Git-история (`--all`), с redaction. Установленные зависимости, build/dist/target/gen, служебные Git-файлы и `.artifacts` не публикуются и исключены из source-сканирования. Ключи, сертификаты и `.env*` исключены `.gitignore`; файлы примеров могут быть добавлены только с фиктивными значениями.

В текущем дереве секреты не обнаружены. Дополнительно проверены имена потенциальных credential-файлов и исходники на пароли/ключи/токены. Нет пользовательских JSON-проектов, SDK, конфигурации EIM, приватных SSH-ключей или бинарных результатов сборки в отправляемом наборе. Персональные абсолютные пути заменены переносимыми примерами в документации. Copyright и публичные авторские метаданные сторонних библиотек сохранены.

Результат сканера – проверка известных шаблонов, а не математическая гарантия отсутствия любых возможных конфиденциальных данных. Если секрет появится в будущей истории, остановите отправку, отзовите его у поставщика и согласуйте решение отдельно; `.gitignore` не удаляет уже закоммиченные данные.

## Изменённые файлы подготовки

Основной код в `src/` и `src-tauri/src/`, архитектура, библиотека, генератор, ESP-IDF и визуальный стиль не изменены.

- Обновлены `.gitignore`, `README.md`, `CHANGELOG.md`.
- `package.json`, `package-lock.json`, `src-tauri/Cargo.toml`: только лицензионные метаданные MIT, версия 0.1.0 и зависимости сохранены.
- Новые `LICENSE`, `THIRD_PARTY_NOTICES.md`, `docs/dependency-licenses.md`, `docs/dependency-licenses.json`.
- Новые `.github/workflows/build-macos.yml`, `src-tauri/tauri.release.conf.json`, `scripts/check-version.mjs`, `docs/releases.md`, этот отчёт.
- `docs/esp-idf.md`, `docs/verification.md`, `docs/verification-stage1.md`, `docs/verification-stage2.md`, `docs/verification-stage3.md`: переносимые пути вместо пользовательских абсолютных; архивные номера этапов сохранены и обозначены как исторические.
- `docs/logic.md`: устранена устаревшая фраза о недоступной сборке после реализованного этапа 4.
- `eslint.config.js`: Node globals для нового служебного script.
- Новый `tests/fixtures/blink-mount-v2.clex.json`, `tests/logic-ui.cjs`: переносимый тестовый JSON вместо зависимости от игнорируемого личного экспорта в `.artifacts`. Сценарий редактора не изменён.

## Проверки

- Версия 0.1.0 совпадает во всех npm/Tauri/Cargo конфигурациях и lockfiles.
- Lint, 49 JS-тестов, 9 Rust-тестов и форматирование прошли.
- UI-сценарий графа с включённым в репозиторий fixture прошёл.
- Проверены version gates: правильный Pre-release допускается, другой тег и стабильный первый релиз отклоняются.
- Workflow YAML читается; SHA Actions разрешены из официальных репозиториев, триггеры только manual/release-published, права содержимого read-only.
- Официальный Tauri CLI собрал проверочную **debug ARM64** `.app`/`.dmg` с release overlay. `hdiutil verify` подтвердил DMG; `.app` имеет ad-hoc подпись, версия 0.1.0, LICENSE/THIRD_PARTY_NOTICES точно совпадают с исходными файлами.
- Сборка потребовала системных Disk Images операций вне песочницы; результат остаётся локальным и игнорируется Git.

Оптимизированная release-сборка в GitHub Actions, Developer ID, нотариализация, установка на чистом Mac и физическая ESP32-S3-ETH ещё не проверены. Стабильный релиз и проверенная аппаратная совместимость не заявляются. Порядок следующих действий описан в [releases.md](releases.md).
