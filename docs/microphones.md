# Внешние микрофоны

В «Монтаже» доступны MAX9814, MAX4466 и INMP441. Подключите контакты модуля и выберите его в поле «Микрофон» компонента «Голосовое управление». Захват звука и распознавание поддерживаются на ESP32-P4 Nano, ESP32-S3-ETH и ESP32-S3-DevKitC-1 N8R8. Встроенный микрофон P4 Nano остаётся доступен без внешнего модуля.

| Модуль | Интерфейс | Особенности |
| --- | --- | --- |
| MAX9814 | Аналоговый OUT → ADC1 | Автоматическая регулировка усиления. Максимальное усиление и отношение атаки/восстановления задаются перемычками модуля. |
| MAX4466 | Аналоговый OUT → ADC1 | Усиление регулируется подстроечным резистором. |
| INMP441 | Цифровой I²S: SCK, WS, SD | Выбираются контроллер I²S и левый/правый канал. |

## Подключение

В поддерживаемых проектах ESP32 микрофоны питаются от **3,3 В**. Подключение к 5 В блокируется. Обозначения и порядок контактов на разных модулях могут отличаться; ориентируйтесь на маркировку своей платы.

Для MAX9814 и MAX4466 подключите VDD, GND и OUT. Вход OUT разрешён только на свободном ADC1. На P4 Nano доступны GPIO20-GPIO23; ограничения остальных интерфейсов платы сохраняются. На S3-ETH входы GPIO1/GPIO2 используют контакты камеры: в свойствах платы укажите отключение камеры после её физического отключения. На DevKitC-1 N8R8 используются свободные входы ADC1 из описания платы. ADC2 не используется.

Для INMP441 подключите VDD, GND, SCK/BCLK, WS/LRCLK и SD. Контакт L/R подключается к GND для левого канала или к 3,3 В для правого. Выбранный канал в настройках должен соответствовать этому подключению. Контроллер I²S должен быть свободен. Если на P4 используется встроенный динамик, его I²S0 занят: для внешнего INMP441 выбирается другой контроллер.

В текущем профиле S3-ETH при подключённой камере не хватает свободных разрешённых GPIO для внешнего INMP441. Отключите камеру либо используйте другую плату. Проверки GPIO, Flash/PSRAM, UART, USB и других интерфейсов сохраняются.

## Запись и распознавание

После выбора микрофона соберите и запишите прошивку. Запись примеров и подготовка модели выполняются через [настройку голосового управления](voice.md). При смене микрофона, GPIO, контроллера или канала I²S прежние записи сохраняются, но не используются для запуска команд с новым источником. В настройке распознавания можно начать новый набор записей, сохранив список команд.

Для внешнего микрофона параметр усиления применяется к цифровой записи. Он не переключает аппаратное усиление MAX9814/MAX4466. Начните с небольшого усиления и проверьте запись; при перегрузке уменьшите усиление на модуле или в настройках. MAX9814 с AGC изменяет усиление автоматически.

Распознавание на S3 работает без звука активации: аудиовыход для этих плат пока не добавлен в каталог. На P4 отдельный компонент «Динамик» поддерживает звук активации и обычные звуковые сигналы совместно с внешним микрофоном.

## Остальные платы каталога

| Плата | Электрическое подключение микрофонов | Голосовое управление в CLEX Flow |
| --- | --- | --- |
| ESP32-P4 Nano | MAX9814/MAX4466 через ADC1; INMP441 через свободный I²S | Поддерживается |
| ESP32-S3-ETH | Внешние микрофоны при отключённой камере и свободных GPIO | Поддерживается |
| ESP32-S3-DevKitC-1 N8R8 | MAX9814/MAX4466 через ADC1; INMP441 через свободный I²S | Поддерживается |
| ESP32 DevKit V1 WROOM-32, 30 pin | Аналоговые модули через ADC; INMP441 через I²S, питание 3,3 В | Эта реализация распознавания требует PSRAM и для профиля WROOM-32 не поддерживается |
| Arduino Nano ATmega328P | MAX9814/MAX4466 через аналоговый вход; для INMP441 нет штатного I²S | Эта реализация распознавания не поддерживается |
| Общий профиль ESP32-S3 | Контакты не описаны | Выберите конкретную плату |

Внешние микрофоны в этой версии интегрированы как источники голосового управления. Электрическая совместимость с другими платами не включает поддержку записи или распознавания в CLEX Flow.
