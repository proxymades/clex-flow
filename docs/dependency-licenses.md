# Лицензии зависимостей 0.1.0

Проверены текущие `package-lock.json` и Cargo resolution для **aarch64-apple-darwin**: 241 npm-запись (включая development/optional) и 265 Cargo-пакетов (включая build/test). Версии не обновлялись. [Машиночитаемый список](dependency-licenses.json), [уведомления и полные тексты](../THIRD_PARTY_NOTICES.md).

Для оригинальных файлов CLEX Flow добавлена **MIT License**. Она не заменяет условия сторонних библиотек. В проверенном дереве нет GPL/AGPL-зависимостей, которые потребовали бы лицензировать собственный код CLEX Flow под ними.

Основные JS-библиотеки React, React DOM, React Flow, Lucide и Tauri JS API используют разрешительные лицензии. Среди транзитивных зависимостей есть MIT, Apache-2.0, ISC, BSD, Python-2.0 и Unicode-3.0. `caniuse-lite` под CC-BY-4.0 – build-time данные; его отдельная лицензия/атрибуция сохранены, это не лицензия приложения.

## MPL-2.0

Обнаружены `cssparser 0.29.6`, `cssparser-macros 0.6.1`, `dtoa-short 0.3.5`, `option-ext 0.2.0`, `selectors 0.24.0`. Они не перелицензируются под MIT. Файловые обязанности MPL относятся к соответствующим компонентам/модификациям; сам факт использования не требует поменять лицензию всех оригинальных файлов приложения. При распространении бинарников нужны доступность покрытых исходников и уведомление получателей. Точные source archives и тексты MPL сохранены в THIRD_PARTY_NOTICES; сторонние исходники не изменялись. Основание: [Mozilla MPL FAQ, вопросы 8 и 11](https://www.mozilla.org/en-US/MPL/2.0/FAQ/).

## Сохранение уведомлений

Скопированы license/notice-файлы установленных пакетов; одинаковые тексты дедуплицированы с сохранением списка пакетов и источников. Для crates без такого файла уведомления получены из upstream, преимущественно по неизменяемому commit из `.cargo_vcs_info.json`. Несколько старых пакетов не поставляют отдельного файла лицензии; их объявленная лицензия, исходники и имеющиеся авторские метаданные перечислены отдельно, права владельцев не подменены. Для отсутствующих на этом Mac optional npm-пакетов зафиксированы метаданные lockfile; их бинарники не входят в macOS-поставку.

Release overlay включает `LICENSE` и `THIRD_PARTY_NOTICES.md` в `Contents/Resources` приложения. Локальный процесс разработки не изменён. Перед распространением следующей сборки после обновления зависимостей нужно пересоздать и проверить этот список; он является снимком конкретных lockfiles, а не бессрочным разрешением для любых будущих библиотек.

ESP-IDF, пользовательский Python и macOS frameworks не копируются в поставку приложения. Лицензирование генерируемой firmware и дополнительных аппаратных модулей следует оценивать для конкретного будущего MCU-эксперимента/поставки отдельно.
