# Голосовое управление

Компонент «Голосовое управление» распознаёт собственные короткие фразы на Waveshare ESP32-P4 Nano со встроенным микрофоном и кодеком ES8311. В «Монтаже» задаются фразы и записи, а блок «Голосовые команды» в «Логике» предоставляет отдельный выход события для каждой фразы. Назначение действий определяется соединениями графа.

## Подготовка

1. Добавьте «Голосовое управление» в проект P4 Nano. Список команд изначально пустой.
2. Введите свои фразы. Желательно выбирать различимые команды длительностью до 2,4 секунды.
3. Укажите количество повторов, примеров посторонней речи и фона. Перед началом мастер показывает число записей и примерное время. Можно прервать сеанс и продолжить позже.
4. Откройте «Настроить распознавание», выберите USB-порт, соберите прошивку и запишите её на плату. Эта операция заменяет текущую программу. Первая прошивка позволяет записывать голос до подготовки модели.
5. На вкладке «Записи» запустите сеанс. Каждая трёхсекундная запись начинается отдельной кнопкой после обратного отсчёта. Произносите показанную фразу после надписи «Говорите». Активацию «Привет ESP» в обучающие записи добавлять не нужно. Для фона сохраняйте тишину; для посторонней речи произносите фразы, отсутствующие в списке команд.
6. Прослушайте записи при необходимости, удалите и повторите неудачные. Приложение отклоняет перегруженный звук, отсутствие речи и фразы, обрезанные концом записи.
7. На вкладке «Модель» запустите подготовку. Приложение выделит проверочные примеры, подберёт пороги и покажет число правильных, отклонённых и ошибочных распознаваний. Модель с перепутанными или ложными командами на этих проверках не допускается к исполнению. Добавьте примеры или замените похожие фразы и повторите подготовку.
8. Соберите и запишите обновлённую прошивку. На вкладке «Проверка» проверьте свои фразы, постороннюю речь, расстояние и обычный фон помещения. Проверка сверяет модель проекта с прошитой моделью. Действия графа продолжают выполняться во время проверки.

Запись и подготовка доступны в десктопном приложении. Звук записывается микрофоном платы и передаётся по USB. Подготовка модели выполняется локально на компьютере, без отдельной установки Python или сервисов распознавания. Для выполнения команд после прошивки компьютер, сервер и интернет не требуются.

## Работа на плате

Плата ожидает активацию «Привет ESP» с готовой русской моделью WakeNet10. После активации звучит двухтональный сигнал. С его окончания начинается окно команд, по умолчанию 20 секунд. Внутри окна можно произнести несколько команд; они не продлевают таймер. После закрытия окна плата возвращается к ожиданию активации. Неуверенное распознавание не запускает событие конкретной команды.

Блок «Голосовые команды» предоставляет:

- отдельное событие для каждой своей фразы;
- общее событие распознавания, текст и ID команды;
- события активации, неуверенного распознавания, закрытия окна и ошибки.

Изменение текста фразы сохраняет ID и соединения её выхода, но требует новых записей этой фразы и повторной подготовки модели. При удалении связанной команды граф показывает ошибку отсутствующего выхода. Добавление команд также требует подготовки и прошивки новой модели.

## Ограничения

- Первая версия поддерживает встроенный аудиоинтерфейс ESP32-P4 Nano. Одновременно допускается один голосовой компонент. Отдельный компонент «Динамик» использует тот же кодек и конфликтует с ним; для звука выберите голосовой компонент в блоке «Звуковой сигнал».
- До 32 команд и 128 записей в одном наборе. Число повторов задаётся отдельно; минимально нужны три записи каждой команды и по две записи посторонней речи и фона. Примеры для настройки порога и независимой проверки выделяются из записанного набора. При двух записях отрицательного класса отдельного тестового примера для него нет.
- Используется сравнение звуковых признаков с записанными примерами. Это персональная модель коротких фраз, а не распознавание произвольного текста. Для других голосов и условий нужны дополнительные записи и отдельные проверки. Результаты на записанном наборе не гарантируют точность в других условиях.
- Звуковые признаки и модель сохраняются в файле проекта. WAV для прослушивания хранятся локально в данных приложения. При переносе проекта на другой компьютер распознавание и прошивка сохраняются, а исходные аудиозаписи для прослушивания могут быть недоступны.
- Компонент резервирует раздел Flash для готовой модели активации. Перед прошивкой сохраняйте нужную предыдущую программу и настройки устройства.
