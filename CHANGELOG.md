# Изменения CLEX Flow

## 0.1.0 – Work in Progress, планируемый Pre-release

Первый согласованный номер приложения после этапов 1-4. Предыдущие номера этапов не являются восстановленными Git-релизами. Номер приложения – 0.1.0; тег и официальный Release пока не созданы.

- Локальные JSON-проекты, импорт/экспорт, поиск, сохранение и защита несохранённых изменений.
- SVG-монтаж ESP32-S3-ETH и DevKitC-1 v1.1 N8R8, LED с резистором и кнопка, проверки GPIO.
- React Flow, пять логических блоков, типизированные связи, Undo/Redo и автосохранение.
- Фиксированная генерация ESP-IDF-проекта, просмотр исходников, поиск существующей ESP-IDF 5.4.4.
- Реальная компиляция и журнал, отмена процесса, выбор serial-порта, запись актуальной сборки с подтверждением, монитор 115200 бод.

На macOS подтверждены программные проверки, сборка приложения и генерация настоящих бинарников. Физическая прошивка, работа LED/кнопки и Serial устройства не испытаны. Стабильного релиза нет. Публикация установщиков через GitHub Releases ожидает отдельной проверки и разрешения.

### Подготовка публичного репозитория

- MIT для собственного кода, отдельные уведомления и источники лицензий зависимостей.
- `.gitignore` для зависимостей, сборок, локальных конфигураций и секретов; lockfiles сохраняются.
- Проверка согласованности версии, инструкция выпуска и release overlay без изменения локальной разработки.
- Workflow Apple Silicon `.app`/`.dmg` с явными триггерами и артефактами для проверки; автоматической публикации установщиков нет.
